# Projeto Piloto Dados

Este projeto apresenta uma base de dados sobre filmes do IMDb

## Arquivo de Dados

O arquivo dados/tab_imdb.csv/ contém informações que podem ser utilizadas para realizar análise sobre filmes. Avaliações e bilheteria.

## Scripts 

A pasta de scripts contém sub-pastas de arquivo em extensão python (arquivo de visualização do dataframe),  e extensão sql(query para trazer dados do banco).
